# 功能二 v4：长轨粗切 + 细切划分子任务（本地）

> 日期：2026-08-18  
> 状态：**方案已定 / 本地已落地**；500+ 步长轨用户初验可用  
> 前置：v1 文本整轨、v2 关键帧看图（≤12 张/整轨）、v3 录制增强（hotkey/hover）  
> **本阶段仅本地 `subtask_splitter.py` + 标注页一键；不部署 cloud_server**

---

## 1. 背景与问题

| 现象 | 原因 |
|---|---|
| 几十～一百多步可划分 | v2 整轨一次请求尚可 |
| 几百～上千步划分失败或质量差 | 整轨 JSON 过大；整轨仅 12 张图过稀；模型一次输出覆盖 0..N 易截断/漏段 |

v4 目标：**长轨也能稳定划分**，且块内 `instruction` 仍依赖截图写清楚。

---

## 2. 总体流程

```text
trajectory (0 .. last)
    │
    ├─ 步数 ≤ 阈值 ──► 整轨单次划分（与 v2 相同路径，兼容短轨）
    │
    └─ 步数 > 阈值 ──► 分层划分
            │
            ├─ 1) 压缩整轨摘要
            ├─ 2) 粗切（1 次模型，文本为主，0 图）
            │      → 若干 chunk: {start_step, end_step, theme}
            ├─ 3) 细切（每 chunk 1 次，≤16 张图/chunk；窗口含与上一块的重叠步）
            │      → 块内 sub_tasks（全局 step 号）
            └─ 4) 重叠区择优归属 + 压成不重叠 sub_tasks + validate + 必要时修补
```

---

## 3. 粗切（Coarse）

### 3.1 输入

- 压缩后的**整轨**动作摘要（去掉截图路径、空字段、合并连续同类动作）
- 可选：启发式边界提示（hotkey / hover / type↔click 切换等）

### 3.2 输出

```json
[
  {"start_step": 0,   "end_step": 127, "theme": "登录并进入主界面"},
  {"start_step": 128, "end_step": 263, "theme": "检索并导出数据"}
]
```

- 必须连续覆盖 `0 .. last`，无缺口；模型输出的粗切层先规范成**核心区间互不重叠**
- 规范后为细切给后一块加上向前重叠（默认 8 步），并保留 `core_start` / `core_end`
- `theme` 供细切作上下文，**不是**最终 `instruction`

### 3.3 块大小后处理

| 规则 | 默认 |
|---|---|
| 目标块长 | ~100 步 |
| 最小块 | 40 步（过小则与相邻合并） |
| 最大块 | 180 步（过大则在中部再劈） |

### 3.4 失败回退

模型粗切失败 → **启发式等分**（按目标块长切），保证细切仍能进行。

### 3.5 模型

- 可用 `DUCKTRACK_SUBTASK_COARSE_MODEL`（未设则与 `DUCKTRACK_SUBTASK_MODEL` 相同）
- 建议长上下文文本模型；粗切默认**不传图**

---

## 4. 细切（Fine）

对每个 chunk `[start .. end]`：

1. 生成**块内压缩摘要**（全局 step 号，仅该区间）
2. 在块内抽关键帧，**最多 16 张**（`DUCKTRACK_SUBTASK_MAX_IMAGES`）
3. 调用 VL 模型，Prompt `subtask-split-v3`
4. 输出块内 sub_tasks，`start_step/end_step` 为**全局**索引

### 4.1 抽帧策略（块内）

与 v2 类似，但范围限定在 chunk：

- 块首尾步
- 块内动作族边界（含 `hotkey`、`hover`）
- 均匀代表帧补足至上限

### 4.2 细切 Prompt 要点

- 携带 `chunk_theme`
- 以截图写具体 `instruction`
- 索引必须落在 `chunk_start .. chunk_end` 且连续覆盖该区间

---

## 5. 合并与校验

1. 粗切核心区间仍首尾相接；后一块细切窗口的 `start_step` 向前延伸 `CHUNK_OVERLAP` 步（不超过上一块 `core_start`）
2. 各块在**各自窗口**内独立细切（含重叠步）
3. 先把各块核心区间画上归属；重叠区比较两侧得分后整段给赢的一侧：  
   得分优先 **单段完整覆盖重叠区** → **更高 confidence** → **更少碎段**；平局留左侧（重叠落在左核内）
4. 按步压缩成互不重叠的 `sub_tasks`，重排 `index`
5. `validate_sub_tasks`；若仅轻微缺口：自动延伸相邻段或插入 `needs_review` 段（不整轨失败）
6. `DUCKTRACK_SUBTASK_CHUNK_OVERLAP=0` 时退回直接拼接，不走重叠裁决

metadata / 调试：

- `splitter`: `qwen_subtask_v3`（或等价名）
- `prompt_version`: `subtask-split-v3`
- `hierarchical`: true
- `coarse_chunks`: 含 `core_start` / `core_end` 与细切窗口
- `chunk_overlap` / `overlap_merges`: 重叠步数与每段左右胜负

## 6. 环境变量（本地）

| 变量 | 默认 | 说明 |
|---|---|---|
| `DUCKTRACK_SUBTASK_HIERARCHICAL` | `1` | `0` 强制整轨单次（短轨行为） |
| `DUCKTRACK_SUBTASK_HIER_THRESHOLD` | `150` | 超过该**可划分步数**启用粗切+细切 |
| `DUCKTRACK_SUBTASK_CHUNK_TARGET` | `100` | 粗切块目标长度 |
| `DUCKTRACK_SUBTASK_CHUNK_MIN` | `40` | 最小块长 |
| `DUCKTRACK_SUBTASK_CHUNK_MAX` | `180` | 最大块长 |
| `DUCKTRACK_SUBTASK_CHUNK_OVERLAP` | `8` | 后一块细切窗口向前重叠步数；`0` 关闭重叠合并 |
| `DUCKTRACK_SUBTASK_MAX_IMAGES` | `16` | **每个细切块**最多传图数 |
| `DUCKTRACK_SUBTASK_COARSE_MODEL` | （空） | 粗切专用模型，空则用 SUBTASK_MODEL |
| `DUCKTRACK_SUBTASK_VISION` | `1` | 细切是否看图 |
| `DUCKTRACK_SUBTASK_FALLBACK_TEXT` | `1` | 块内无图时回退文本 |

**不修改** `start_annotator.bat` 中用户已配好的模型；上述变量可选追加。

## 7. 与 v2 对比

| | v2 | v4 |
|---|---|---|
| 请求次数 | 1 | 1 + chunk 数 |
| 单次传图 | 整轨 ≤12 | 每 chunk ≤16 |
| 800 步图密度 | 极稀 | 块内较密 |
| 短轨 | 整轨 | 仍走整轨（≤阈值） |
