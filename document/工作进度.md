| 侧栏按子任务分组 | ✅ | |

| V3 顶栏路径/状态可读可复制 | ✅ | 禁止换行挤压；悬停卡片 + 一键复制 |

**功能二现行用法（本地）：**

1. 用根目录 `start_annotator.bat` 启动（会注入模型环境变量；**Token 仅本机填写，勿提交仓库**）  
2. 打开本地录制目录进入标注 → **「模型划分子任务」**  
3. **≤150 步**：整轨划分（v2 路径）；**>150 步**：自动粗切+细切（v4）  
4. 细切每块最多 **16 张**关键帧（`DUCKTRACK_SUBTASK_MAX_IMAGES`，代码默认 16）  
5. 可 **「撤销模型划分」** → 保存

## 轨迹中当前会导出的动作（2026-08-16）

> **完整说明（目录结构、逐步字段、各动作 parameters）：** `document/DuckTrack录制轨迹数据说明.md`（2026-08-20，对照样例 `output/recording-2026-08-20_17-10-27`）

| 动作名 | 侧栏含义 | 说明 |
|---|---|---|
| `click` | 左键单击 | |
| `rightClick` | 右键单击 | |
| `doubleClick` | 左键双击 | |
| `doubleRightClick` | 右键双击 | |
| `dragTo` | 拖拽 | |
| `scroll` | 滚轮滚动 | 短时连续滚动可合并 |
| `hover` | 鼠标悬停 | ≥5s 才记；`duration`=实际停留；`DUCKTRACK_HOVER_DWELL_S` 可调 |
| `type` | 文字输入 | 连续可打印字符合并；**仅 Shift+字母仍为打字** |
| `hotkey` | 快捷键 | Ctrl/Alt/Win（可加 Shift）+ 主键，支持三键如 Ctrl+Alt+A |
| `keyDown` / `keyUp` | 按键按下 / 释放 | 特殊键或未合成热键的修饰键等 |
| `pause` / `resume` | 录制暂停 / 恢复 | |
| `terminate` | 结束 | 停止录制后自动追加 |

**不会自动导出：** `moveTo`（界面有名、普通移动不记）；`wait`（代码占位、当前不插入）。
