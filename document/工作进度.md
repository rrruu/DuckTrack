## 当前实际可用能力（用户视角）

本产品主界面：**在当前应用内控制录制，不启动独立录制窗口。**  
开始录制后**不会弹出浮窗**。

| 能力 | 当前是否可用 | 说明 |
|---|---|---|
| 整段连续录制 | ✅ | |
| **录中**切分子任务 | ❌ | 主流程无浮窗 |
| **录后**人工划分子任务 | ✅ | 拆分 / 合并 / 填意图 |
| 侧栏按子任务分组 | ✅ | |
| **模型一键划分子任务 + 撤销** | ⚠️ 源码已实现 | 需重新 build 前端；且后端/云端需配置 `DUCKTRACK_QWEN_URL` |
| 上传后自动划分子任务 | ❌ | 延后 |
| 本地一键填逐步意图/结果 | ❌ | 仍仅云端逐步标注 |

**功能二现行用法（实现后）：**

1. 打开标注页（本地目录，或云端会话缓存）  
2. 点 **「模型划分子任务」** → 整轨覆盖生成分段  
3. 不满意点 **「撤销模型划分」**  
4. 满意则保存（云端会话会走原有 reviewed 保存逻辑）  

有云端会话时优先调云端划分 API；否则调本地后端（需本机后端环境变量里配置模型 URL）。

## 验收提醒（功能二）

1. `tauri build` 后启动 annotator  
2. 确保云端（或本地后端）已配置 Qwen URL  
3. 标注页点「模型划分子任务」→ 检查分段与 `source=model`  
4. 点「撤销模型划分」→ 应恢复上一版  
5. 失败时（未配置模型）应有明确错误，且不覆盖原分段
