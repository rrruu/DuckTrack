## 当前实际可用能力（用户视角）

本产品主界面文案为：**在当前应用内控制录制，不启动独立录制窗口。**  
开始录制后**不会弹出浮窗**；录制控件在主窗口「1 · 录制」卡片中（开始 / 暂停 / 继续 / 停止并加载）。

| 能力 | 当前是否可用 | 说明 |
|---|---|---|
| 整段连续录制 | ✅ | 与改前相同 |
| **录中**点「下一子任务」切分 | ❌ | 主流程无浮窗，主窗口录制区也无该按钮；用户无法边录边切 |
| **录后**在标注页划分子任务 | ✅ | **当前主用方式**：拆分 / 合并 / 填意图 / 保存 |
| 侧栏按子任务分组展示 | ✅ | 标注页 |
| 模型自动划分子任务（功能二） | ❌ | 按钮预留且禁用 |

**现行标准使用流程：**

1. 主窗口点「开始」→ 选目录 → 操作桌面 →「停止并加载」  
2. 进入标注页，此时轨迹多为单段（或旧数据自动补成单段）  
3. 用「从此步拆分子任务」「与上一段合并」统一划分  
4. 填写各子任务 `instruction`，保存  

暂不要求边录边划分；先使用「先整段录完，再在标注里统一划分子任务」。

## 建议验证方式（符合实际）

1. 用当前可运行的 annotator 启动（若改过前端源码需已成功 `tauri build`）。  
2. 主窗口完成一次整段录制 →「停止并加载」。  
3. 在标注页：  
   - 侧栏是否按子任务分组  
   - 「从此步拆分子任务」「与上一段合并」是否可用  
   - 填写子任务意图后保存，`trajectory.json` 中是否有 `sub_tasks` / `sub_task_metadata`  
4. **不要**以「浮窗是否出现 / 录中是否能切分」作为本阶段验收标准。
