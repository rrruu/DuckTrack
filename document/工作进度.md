## 当前实际可用能力（用户视角）

本产品主界面：**在当前应用内控制录制，不启动独立录制窗口。**  
开始录制后**不会弹出浮窗**。

| 能力 | 当前是否可用 | 说明 |
|---|---|---|
| 整段连续录制 | ✅ | |
| **录中**切分子任务 | ❌ | 主流程无浮窗 |
| **录后**人工划分子任务 | ✅ | 拆分 / 合并 / 填意图 |
| 侧栏按子任务分组 | ✅ | |
| **模型一键划分子任务 + 撤销** | ✅ | 本地已验收（SiliconFlow + Qwen3.6-27B）；代码已推 GitHub |
| 上传后自动划分子任务 | ❌ | 延后 |
| 经远端 cloud_server 一键划分 | ⏳ | 需师兄/维护方更新远端部署；本地直连模型已可用 |
| 本地一键填逐步意图/结果 | ❌ | 仍仅云端逐步标注回流 |

**功能二现行用法（本地模型）：**

1. 在 `start_annotator.bat` 配置 `DUCKTRACK_QWEN_URL` / `TOKEN` / `MODEL`（**Token 仅本机填写，勿提交仓库**）  
2. 用该 bat 启动 → 打开本地录制目录进入标注  
3. 点 **「模型划分子任务」** → 整轨覆盖生成分段  
4. 可点 **「撤销模型划分」** 恢复上一版 → 保存
